# X 文字数チェッカー (moji-tool / T-0001)

ブラウザ内完結の静的ページ。X(旧Twitter)の重み付き文字数(上限280)を数える。外部通信・トラッキング・外部依存なし(CSPで外部接続を遮断)。

## ファイル
- index.html : UI
- counter.js : カウントロジック(DOM非依存、node/ブラウザ両対応)
- app.js : UI結線
- tests/counter.test.js : 単体テスト

## 使い方
index.html をブラウザで開く。テスト: `node --test tests/` (Node 18+)

## ルール(根拠: _context/T-0009 の一次情報 twitter-text config v3)
- 重み1: U+0000-10FF, U+2000-200D, U+2010-201F, U+2032-2037。それ以外は2(全角英数・半角カナ含む)
- 絵文字は1つで2(ZWJ/肌色/国旗/キーキャップ含む)、URLは一律23、改行は1、上限280、NFCで正規化
- 設定は counter.js の CONFIG / analyze(text, options) で変更可能

## 公式との突き合わせ(T-0013 / T-0023で反映)
- counter.js は公式 twitter-text 3.1.0 の parseTweet とコーパス3630件で突き合わせ済み(3609件一致、不一致21件は全て根拠付き。詳細は T-0013/REPORT.md)。
- 同梱物は自作(公式コードは含まない)。TLD表(公式が認識するIANA TLD)を埋め込み、counter.js は約16KB(gzip約8KB)。
- node計測: 読み込み+初回analyze 中央値 約1.6ms、280字の再計算 約0.37ms/回(旧実装 約0.03ms)。キー入力ごとの再計算で問題ない水準。実ブラウザ・実機の計測は未実施(T-0014)。

## 既知の制約・未確認
- 公式との既知の差(21件中18件): 公式の絵文字表がEmoji 12止まりのため、新しい絵文字(🫶 等、ZWJ列含む)を公式は分解して数える。本実装は絵文字1つ=2。X本番の実挙動は未確認で、どちらに合わせるかは未判断。
- 残り3件: 公式URL検出の癖(非ASCII文字直後のハイフン始まりドメイン)。通常の文章ではほぼ発生しない。他にも公式の癖は一部のみ再現(ファズ90000件で未文書化の不一致0)。
- 検証対象は twitter-text 3.1.0 の parseTweet。X本番の最新実装との一致は保証しない。
- 返信先の自動@メンション非カウント、メディア0、Premium長文上限は未対応
- 実ブラウザ(Chrome/iPhone Safari)での表示確認は未実施(node単体テストのみ)
- 広告・計測・公開は含まない(後続/承認待ち)
